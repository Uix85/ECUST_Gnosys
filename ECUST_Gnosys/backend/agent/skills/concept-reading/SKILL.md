# concept-reading

本技能只讲**工具怎么用**。判断标准（怎么定位义项、侧重何时写）在任务提示里。

## 大多数情况下不需要调工具

任务输入里已经给了：这一句、整段原文、邻近段落、该段的语义层解释、以及（若有）该词已有的意义地图。
直接判断即可。注意：`semantic_layer` 是上一层生成的解释，**只能当参考，不能当原文依据**。

## 唯一的工具：`locate_term_context`

| 参数 | 用法 |
|---|---|
| `term` + `chapter_idx` + `paragraph_index` | 定位这一处 |
| `window` | 需要更远的邻段时调大（0–2）。大多数情况不用调 |

返回 `paragraph_text`（会进材料账本）、`neighbors`、`semantic`（该段的语义层解释）、`note_state`。
`note_state: null` 表示该段没有语义层笔记 —— 正常降级，不是错误。

## 本任务故意不提供全书检索

如果你发现要判断这一处读法，必须看全书分布或作者的定义段落，**不要硬猜**：
把 `needs_mapping` 设为 true、`reading` 留空交上去，系统会去后台建图，下次划同一个词就用得上地图了。

## 红线

- 引文逐字取自本次已读原文（账本机制：只有读原文的工具会记账，核验只认账本）。
- 不许上网、不许看别的书、不许引用没读过的原文。
- 已有地图与你判断冲突时说明理由，不要硬合并。
- 同一工具同一参数不要重复调用；能交出合规结果就立刻交卷。
