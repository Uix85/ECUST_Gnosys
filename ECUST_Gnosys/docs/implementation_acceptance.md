## 验收结果

- [x] 原文坐标：唯一目录节点、父子路径、段落范围和指纹；搜索、书签、笔记及 Agent 引用共用坐标，文本变化会让旧引用失效。
- [x] 数据迁移：SQLite WAL 一致性备份、版本表、事务回滚；旧笔记保持可读，不删除原表。
- [x] 导入：EPUB/TXT、UTF-8/UTF-16/检测编码、标题层级、保留上传文件名；同名书籍隔离，损坏或空文件不进入书库。
- [x] 阅读工作台：书库搜索与继续阅读、全文搜索、书签、原文定位、字号/行距设置；导航和 Agent 面板支持拖动并记住宽度。
- [x] 四层 Markdown 笔记：共享查看、编辑、预览、保存、导出、离开提醒和并发冲突保护；冲突保留输入并允许下载副本。
- [x] L1 全书层：按段落分块读取完整全书，保存覆盖进度和证据后再汇总，不以目录抽样替代全文。
- [x] L2 章节层：章级总纲、论证区块、转折、衔接及可跳转来源；集成检查覆盖通用与贺麟规范。
- [x] L3 语义层：段落、详细和逐句解释；接入章节结构与自适应上下文，发布到段落旁注。
- [x] L4 概念层：划词检查、意义地图、当前位置解释、定义/范围/演化证据；同一概念在另一个位置复用经指纹检查的地图。
- [x] 四层任务：页面/API 主动发起、预算与超时、来源及结构校验、独立复核、一次修订、待核稿、取消/重试；候选稿与手工修改冲突时不覆盖。
- [x] 按书 Agent 会话：新建、切换、重命名、删除、追问、停止、重试、复制、导出、保存为笔记。
- [x] 引用：多条划线引用、目录任意层级 `@` 搜索补全、上下键/Enter/Esc、可移除并回到原文。
- [x] 对话执行：Agents SDK 流式 Runner 与 SQLiteSession、只读书籍工具、工具状态、原文来源、编号 SSE 续接、幂等请求和单会话并发保护。
- [x] Markdown：本地固定版本渲染表格、嵌套列表、任务列表、引用、代码高亮、删除线、链接及数学公式；流式/历史共用渲染器，并清理危险 HTML 和链接。
- [x] 恢复：浏览器刷新后续接且不重复内容；取消、模型失败及真实服务进程强制重启均保留部分回答并可重试；服务重启后候选稿可采纳。
