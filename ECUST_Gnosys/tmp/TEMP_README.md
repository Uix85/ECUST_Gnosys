# tmp/ —— 临时产物目录

**这里的东西随时可以整个删掉，不要往这里放需要长期保留的文件。**

约定（2026-10 起）：

1. 脚本产生的临时文件**一律写进本目录**，文件名统一加 `tmp_` 前缀。
2. 不要把临时文件写在 `books/` 里 —— 那是书库数据目录，混进临时文件容易
   被误当成数据，也难以清理（曾经因为跑批脚本被中断，在书库旁留下一份
   未还原的 `book.db.batchbak` 和一个被改过的 `book.db`）。
3. 本目录的内容不进版本库（见根目录 `.gitignore`），只有本说明文件例外。
4. 清理方式：`rm -rf tmp/*`（本说明文件除外），或直接删整个目录再重建。

已知会在本目录写东西的地方：
- `tools/run_batch.py` —— 跑真模型批测前备份的书库文件 `tmp_<书>_book.db.batchbak`
