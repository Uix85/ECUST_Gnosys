## 阅读提示

- `提示词与工作流` 中的入口指向项目内提示词参考文件；正式提示词配置以对应 Dify 工作流为准。
- `backend_prompt_v1.2.md` 属于较早版本参考材料；使用时请结合对应 PRD 和当前工作流核对。
- 当前产品需求以 `产品需求文档/当前产品需求.md` 为准；历史 PRD 和旧任务清单保留在 `reader/PRDs/`，并已标注历史状态。
- 访谈材料同时收录修订版和早期周次材料，引用时请留意版本。
