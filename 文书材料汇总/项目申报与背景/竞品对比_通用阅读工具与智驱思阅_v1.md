# 竞品对比：通用阅读工具 vs 智驱思阅

> 用途：供系统结构图、申报书和答辩材料制图参考。  
> 比较口径：Kimi、NotebookLM、Elicit 的产品定位不同，本表只按“哲学社会科学长文本深度阅读”场景比较，不评价其通用检索、问答或文献发现能力。

## 一句话对比

- **通用阅读工具（Kimi、NotebookLM、Elicit 等）**：以即时问答、摘要和检索为入口的通用工具。
- **智驱思阅**：以四层阅读空间和原文证据为约束的辅助阅读工作台。

## 对比表

| 维度 | 通用阅读工具 | 智驱思阅 | 竞品短板 | 本项目解决什么 |
|---|---|---|---|---|
| **阅读模式** | 以即时问答、摘要、检索为入口，阅读路径由用户当前问题驱动，长文本容易切成回答片段。 | 全书层 → 章节层 → 语义层 → 概念层四层阅读 + 对话；先建立全书/章节结构，再进入段落和术语。 | 读完难形成稳定的整体结构，问答之间缺少连贯框架。 | 把长文本组织成可切换、可回看的分层阅读空间。 |
| **证据锚定粒度** | 引用多停在文档、检索片段或段落摘录；跨轮对话和笔记之间缺少统一坐标，回跳不稳定。 | 章/段坐标 + 文本指纹 + 原文引用；四层成果、笔记、对话共用同一坐标，可从辅助内容回到原文。 | 引文难核验，跨轮、跨功能位置容易漂移。 | 把证据锚定到章/段/句，并贯穿阅读、笔记和对话。 |
| **阅读空间** | 聊天窗口、摘要页、笔记区彼此分离；NotebookLM 有来源面板，但缺少四层并列的阅读工作区。 | 书库/正文/目录/搜索/书签 + 四层辅助内容 + 原文交互 + 对话入口，在同一工作区切换。 | 阅读过程被切成互不关联的片段。 | 在同一工作区连续处理全书、章节、段落和概念。 |
| **任务模式** | 用户临时提问或生成摘要；每次任务相对独立，结果依赖提示词，缺少分层任务契约和统一校验。 | 四层任务后台自动生成、自动校验，读者直接阅读；对话即时回答；不设任务/待核流程。 | 重复劳动、结果不稳定，质量难比较。 | 分层任务契约 + 证据/质量校验 + 自动生成稳定材料。 |
| **人机定位** | AI 主要给答案，读者被动追问；判断责任在读者，但缺少结构化辅助和证据对照。 | AI 作为受原文证据约束的阅读助手，提供结构、解释和证据；读者保留判断，带着结构阅读。 | 容易把模型输出当结论，或需要读者自行校验。 | 辅助不替代，证据可回溯，读者带着结构判断。 |

## 制图版式建议

建议画成左右双栏、五行对比：

```text
┌──────────────────────────────┬──────────────────────────────┐
│ 通用阅读工具                  │ 智驱思阅                     │
│ Kimi / NotebookLM / Elicit   │ 四层阅读 + 对话              │
├──────────────────────────────┼──────────────────────────────┤
│ 阅读模式：问答/摘要驱动        │ 阅读模式：四层结构驱动        │
│ 证据粒度：文档/片段引用        │ 证据粒度：章/段/句 + 指纹     │
│ 阅读空间：聊天/笔记分离        │ 阅读空间：同一阅读工作区      │
│ 任务模式：临时提问/摘要        │ 任务模式：自动生成 + 校验     │
│ 人机定位：AI 给答案            │ 人机定位：读者带结构判断      │
└──────────────────────────────┴──────────────────────────────┘
```

制图时可用：

- 左侧用灰色或低饱和色，突出“通用、片段化”；
- 右侧用项目主色，突出“分层、可回溯、工作台”；
- 中间放五个维度标签，左右各一句短对比；
- 每行只保留一个核心差异，详细解释放图注或右侧小字；
- 顶部标题建议：**“从问答工具到深度阅读工作台”**。

## 可直接放到图上的短句

- 阅读模式：**问答片段 → 分层阅读**
- 证据锚定：**文档/片段引用 → 章/段/句 + 文本指纹**
- 阅读空间：**聊天/笔记分离 → 同一阅读工作区**
- 任务模式：**临时提问 → 自动分层生成 + 校验**
- 人机定位：**AI 给答案 → 读者带结构判断**

## 备注

- Kimi：通用长文本对话与摘要能力较强，适合快速问答。
- NotebookLM：围绕资料库做摘要、问答和来源引用，接近“资料工作台”，但缺少四层阅读空间。
- Elicit：偏向文献检索、信息抽取和综述，不面向单本书的逐层深读。
- 本表把三者合并为“通用阅读工具”是为了制图简洁；具体产品能力差异可在图注中补充。
